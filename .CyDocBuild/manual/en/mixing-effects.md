## Overview {#overview}

These modules combine several operations into purpose-built panels. Start from a factory preset close to the job, then change one aspect at a time. Preserve headroom around nonlinear and multiband stages, and level-match bypass comparisons.

## Choose a module {#modules}
| Module | Role |
| --- | --- |
| Pression | Upward/downward multiband dynamics; control quiet and loud band behaviour separately. |
| Fournaise | Saturation/colour; check drive, tone and output compensation. |
| Écho Bande | Tape-style delay; time, feedback, coloration and motion interact. |
| Multibande Pro | Frequency-split dynamics; set crossovers before thresholds and band balance. |
| Velours | Resonance taming; listen to removed material and avoid over-smoothing. |
| Patine | Analogue wear, movement and noise; balance character with intelligibility. |
| Sonomètre | Loudness/level analysis; reset integration for a new pass. |
| Tranche | Console-style channel processing; order and gain staging matter. |
| Finition | Mastering/finalisation chain; compare dynamics and tone at matched loudness. |
| Halo | Spacious reverberation; control width, colour, decay and wet balance. |

## Work in stages {#workflow}
For a drum bus, first correct balance on the tracks, then add gentle shared dynamics. For a vocal, repair audible problems before adding character. For mastering, keep a version without final loudness processing and evaluate complete passages, not one peak. Multiband changes can affect crossover phase and perceived balance; compare bands recombined, not only in solo.

## Delay, space and metering {#space}
Feedback repeats can outlast the source; Freeze and high feedback may not decay naturally. A short export range can cut a good tail abruptly. Check send versus insert wet/dry settings and mono compatibility. Metering describes the actual tap it receives; make sure it sits at the point you intend to measure. A louder preset should not automatically win a comparison.
